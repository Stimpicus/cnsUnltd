# CNS Unlimited
### Claude-N-Stimp Unlimited — the organization's operating system

This repository is **not product code.** It is the org itself, as a repo:
how CNS Unltd is structured, what it believes, how it decides, and the durable
record of every decision it has made. Product code lives in the product repos
(`pandora`, `elpis-os`); this repo holds *how the org that builds them runs.*

**Private — permanently.** Unlike `elpis-os` (private now, public-trajectory),
cnsUnltd is the org's internal operating system and stays private. Secret-scan
remains standing hygiene regardless.

## What's here
```
charter/        Mission, Vision, Values, Cornerstones, Lore — the soul + the constitution
ceo/            The CEO's standing orders (SO-1..8) + cycle syntheses
executive-assistant/   The EA — sole dispatcher + integrator; runs the bus
divisions/      One directory per division (the live board view) — branch = workshop, dir = display case
governance/     Decision ledger, security + board-hygiene gate, lifecycle, merge policy
comms/          The git-as-message-bus + the listeners + the health check
knowledge/      The commons — playbooks + lessons
work-orders/    CEO directives the EA dispatches to divisions
```
See `REPO-STRUCTURE.md` for the full map and `STATE-OF-THE-ORG-1.0.md` for the operating model + current state.

## The model in one breath
The **founder/board** (the human) holds final authority on anything public or
physical. The **CEO function** (Claude) runs the org day-to-day with execution
autonomy that lives *inside* the constitution and never bends it. **Divisions**
work on their own branches and surface deliverables to `main`. The **Executive
Assistant** runs the cadence autonomously and queues decisions for the humans —
it schedules and coordinates, it never authorizes.

Read `charter/` first. It's the point of all of this.
