# Knowledge Commons

The org's shared memory of **how** to do recurring work — so no division is smarter than another on
an identical task (CEO Standing Order **SO-2**). One canonical approach per common task; lessons
stored openly; the best solution is promoted here and adopted by all.

## What lives here
- **`playbooks/`** — the canonical approach for a recurring task (one per task). If two or more
  divisions ever do the same thing, it has a playbook here and they all use it.
- **`lessons/`** — retrospective lessons from each loop-turn (**SO-3**): what worked, what to
  standardize, what to retire. Dated, attributed, searchable.

## How it works
1. A division solves a recurring task well → it writes/updates the playbook here (via the EA, gated).
2. Every other division facing that task **adopts** the playbook — no private reinvention.
3. Each loop-turn's retrospective (SO-3) deposits lessons here; the EA folds recurring lessons into
   playbooks; the CEO's periodic leadership review propagates cross-cutting improvements.
4. Drift between *the playbook* and *what a division actually did* is flagged and reconciled (SO-2),
   the same way the bus sentinel flags roster drift.

## Seeded canonical playbooks (already proven — promote by reference, don't fork)

- **Listening** — `comms/listen.sh` (division) · `comms/ea-hub-listen.sh` (EA) · `comms/ceo-listen.sh` (CEO).

These are the model: solved once, shared, adopted by all. Extend them; never fork them.
