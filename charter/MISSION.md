# MISSION — what we are doing

We build **identity-bound, real-time command dispatch** for anything connected —
human or machine — and the **safeguards that decide whether that capability is
catastrophic or beneficial.** Then we give it away.

The capability was already latent in existing technology. We did not create it;
we identified it, named it, and are building the protections that determine what
survives its release. That is the work.

Concretely, right now, we are building:
- **The Pandora Protocol** — substrate-agnostic command dispatch over any
  real-time relational database with subscription delivery, bound to any
  cryptographic identity.
- **Elpis OS** — a consumer operating system that runs on a toaster, is
  Apple-simple but never Apple-locked-down, and puts the user above all else.
- **Face to Face** — zero-retention, device-agnostic real-time communication, the
  first application of the protocol.
- **The disclosure** — the security research (write-to-execute via subscription
  substrate) that makes the danger legible before the capability deploys at scale.

We use **patents to prevent capture** and **disclosure to invite the world in** —
so no corporation can own what we mean to give away, and so the internet can make
it better than Claude-N-Stimp could alone.
